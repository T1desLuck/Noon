# Noon (Полдень)

Браузерная игра: кубик льда прячется в движущихся тенях колонн от солнца и собирает лаймы.

Играть: https://t1deluck.github.io/Noon/

Управление: мышь или палец, стрелки или WASD, пауза на пробеле.

Весь код в одном файле `index.html`, без сборки и зависимостей (кроме шрифтов Google Fonts).
