# Noon (Полдень)

Бесплатная браузерная игра. Ты кубик льда на солнечной террасе: солнце ходит по кругу и тянет за собой тени колонн. В тени кубик остывает, на свету тает. Прячься, собирай лаймы и не дай солнцам себя растопить.

**Играть: https://t1desluck.github.io/Noon/**

Работает на телефоне и компьютере, ничего устанавливать не нужно.

## Управление

- мышь или палец: куда ехать кубику
- стрелки или WASD
- пробел: пауза

## Устройство

Весь код в одном файле `index.html`: без сборки и библиотек (кроме шрифтов Google Fonts). Игра рисуется на canvas.
